J-COUNTER 3.0 – Bitfocus Companion module v3.0.1
================================================

תכולה: תיקוני דוח הבדיקה מ-30.10.2026 למודול jozeemedia-jcounter.
גרסת התוכנה J-COUNTER נשארת 3.0; מספר 3.0.1 מתייחס רק למודול Companion.

חשוב: לא לשנות או למחוק את הגרסה הקודמת v2.0.1.

הכנה לפרסום:
1. לעבוד בענף חדש של המאגר (לא להחליף קבצים ישירות ב-main).
2. להעתיק את תוכן התיקייה הזו אל שורש המאגר.
3. למחוק מהשורש את ששת הקבצים הישנים: main.js, actions.js, feedbacks.js, presets.js, upgrades.js, variables.js. הגרסאות החדשות שלהם נמצאות בתוך src/.
4. ב-Windows להריץ את tools\PREPARE-FOR-REVIEW.cmd. דרוש Node.js 22.20 ומעלה, וגישה לאינטרנט. זה יתקין Yarn 4, ייצור yarn.lock חדש, יריץ בדיקות ויארוז את המודול.
5. להוסיף ל-commit גם את yarn.lock החדש. הוא לא כלול בחבילה מפני שבסביבת ההכנה לא הייתה גישה לרישום החבילות של npm. זה תנאי חובה לפני העלאה לבדיקה!
6. לבצע בדיקת חיבור מול J-COUNTER 3.0: חיבור ראשוני, ניתוק, חיבור חוזר, START/STOP, Feedbacks.
7. לפתוח Pull Request ל-main, להמתין לבדיקות, וליצור tag v3.0.1 רק אחרי הצלחתן.
8. להגיש דרך Bitfocus Developer Portal ולצרף את דוח התיקונים.

תוקן בקוד:
C1–C5, C7 — קובצי תבנית, מעבר ל-src, תצורת Node/Yarn ותלות Prettier.
C6 — הגדרה ל-Yarn 4; נשאר להפיק ולצרף yarn.lock חדש (שלב 4).
M1 / L1 — התאוששות אחרי שגיאות OSC וזמן מקסימלי להמתנה לתשובה ראשונית.
M2 — צבעי Feedback ב-Presets של BLACKOUT, MESSAGE ו-NDI.
L2 — מתועדת אי-התאימות לגרסה v2; לא מבוצעת המרה אוטומטית שעלולה להפעיל פקודה שגויה.
L3 — הוסר המאפיין שלא נתמך ב-API 1.
N1 / N2 — תיקוף מספרים, שילוב Companion Variables בכותרת טיימר.

בדיקות שבוצעו בסביבת ההכנה: בדיקת תחביר Node; 6 בדיקות יחידה עברו.
לא בוצעה אריזת Companion אמיתית משום שלא ניתן היה להתקין תלויות; הרצת סקריפט ההכנה אצלך נדרשת לפני הגשה.
